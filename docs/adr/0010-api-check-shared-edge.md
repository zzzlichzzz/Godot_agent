# ADR-0010. Узкий shared-шов C.12 и companion SHA инвентаря

Статус: принято пользователем, 2026-10-31, ответ «Узкое разрешение».

## Контекст

Промпт C.12 требует повторно использовать чистый inheritance.py C.11, но
R-11 и lint_arch разрешали shared только своей области. Whitelist также
не называл SHA case001 в context/gather/manifest.json.

## Решение

До реализации C.12 уточняется R-11: только фича verification.api_check
может импортировать точное имя python.modules.engine_kb.shared.inheritance.
Другие чужие shared, корни пакетов, class_api/domain и substrate запрещены.
Исключение не распространяется на домен: сбор членов выполняет app.py.
inheritance.py остаётся 1442 B / 38 LF / SHA256 5a9bad5013fbcb3a96d3def0b08118924699b8e3432d12ddf38d75ef0c1e7294.

tools/lint_arch.py меняется только для этой связи, после нового красного
поведенческого теста; мутация должна доказать узость разрешения. Старые
проверки гейта и остальные принятые механики остаются неизменными.

Дополнительно разрешён только SHA записи 001-all-sections в
fixtures/corpus/context/gather/manifest.json. Остальные bytes/EOL/кейсы
манифеста заморожены; разрешённая дельта case001 — api_check/read/count20.

## Следствия

Нового общего пакета, копии inheritance, порта или зависимости на class_api
нет. api_cache.snapshot() вызывается один раз на вызов, состояние не хранится.
Вклад в verify остаётся C.13. Этап6 — сдача аудитору, не приёмка/этап7.
