# ADR 0002. Два процесса: GDScript — руки, Python — голова

- Статус: принято
- Дата: 2026-10-27
- Правила: R-04, R-14, R-01

## Контекст

Godot не исполняет Python. Старый агент работал так: плагин (GDScript) поднимал
локальный сервер, Python-часть (`python/main.py`, 304 КБ) делала анализ и
правки, панель общалась по HTTP. Логика при этом частично дублировалась: в
GDScript появились исполнители (`agent_scene_executor.gd`,
`agent_resource_executor.gd`, `agent_project_settings_executor.gd`,
`agent_mutation_gate.gd`) — то есть «руки» начали принимать решения.

## Решение

Два процесса, граница проходит по **примитивам**:

- GDScript: транспорт (сокет), сессии, главный поток, UI, настройки, выполнение
  примитивов над открытыми сценами и файловой системой редактора.
- Python: домен, анализ, планирование, диффы, политика путей, линт, ошибки,
  каналы (MCP/HTTP/CLI).

GDScript не содержит: разбора `.gd`/`.tscn`, линта, планов, расчёта диффов,
политики путей, прямой записи файлов мимо примитивов, собственной
классификации ошибок.

Примитив — одно действие, один результат. Список примитивов — данные
(`contract/editor_verbs.json`), а не код.

## Следствия

Хорошо:

- одна реализация логики: четыре канала пользуются одним доменом (R-04);
- Python тестируется без редактора (поддельные порты);
- мост остаётся маленьким и его легко переписать;
- при недоступном редакторе домен продолжает работать: возвращается
  `engine_down`, а не падение.

Плохо (принимаем):

- два языка, два рантайма — нужна диагностика «кто не отвечает»;
- состояние открытых сцен нельзя кэшировать в Python: только запрос через
  примитив;
- каждая новая операция над сценой требует явного примитива, иначе Python
  начнёт «знать» про `.tscn` слишком много.

## Альтернативы

| Вариант | Почему нет |
|---|---|
| Вся логика в GDScript | Нет экосистемы Python (линтеры, парсеры, ML), невозможно тестировать без редактора, редактор морозится |
| Вся логика в Python, GDScript только UI | Нельзя корректно менять открытые сцены (undo, зависимости), придётся писать файлы мимо редактора |
| GDScript-мост «умный» (сам решает, что править) | Возвращает дублирование логики и четыре копии поведения |
