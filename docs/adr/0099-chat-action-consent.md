# ADR-0099 — одно разрешение на действия до выхода из чата (D133)

По результатам работы с Qwen пользователь выбрал одну настройку вместо двух плашек. «Разрешить» и «Запретить» решают судьбу текущего запроса. «Разрешить всё» явно включает чтение и применение предпросмотров в текущем чате; общая плашка отключает оба. Старое разрешение только на чтение не мигрирует в разрешение на запись. Это заменяет часть ADR-0097 о раздельных переключателях.

Каждое чтение по-прежнему требует совпадения серверного билета и чата, серия чтений имеет паузу. Каждая запись проходит штатный неизменяемый предпросмотр, решение, журнал и откат. Режим не меняет политики путей и не переносится при смене чата. Выбор варианта на сайте Qwen не является разрешением на его действия.
