# ADR-0095 — проверка завершения процесса Windows по состоянию объекта

- **Дата:** 2026-11-26
- **Уточняет:** ADR-0092, только шаг проверки завершения PID

У завершившегося сервера может оставаться открытый дескриптор, например у
редактора. Его PID ещё доступен через `OpenProcess`, но прежний вызов
`WaitForSingleObject` на дескрипторе с правом `PROCESS_QUERY_LIMITED_INFORMATION`
возвращал `WAIT_FAILED` / `ERROR_ACCESS_DENIED`. Сервер отказывался архивировать
действительно устаревший endpoint. Значение кода выхода `259` также не даёт
однозначной информации: процесс может завершиться с этим кодом.

Запрашивать только право `SYNCHRONIZE`. Считать процесс завершившимся, если
ожидание с нулевым таймаутом вернуло `WAIT_OBJECT_0`, или `OpenProcess` подтвердил
отсутствие PID (`ERROR_INVALID_PARAMETER` для корректного Win32 PID). Недоступный
дескриптор, `WAIT_TIMEOUT`, `WAIT_FAILED` и любой неожиданный статус — не
доказательство завершения. Проверки формы endpoint, эксклюзивного loopback-сокета,
обычного файла и сохранения старых байтов остаются прежними.
