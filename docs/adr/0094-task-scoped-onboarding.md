# ADR-0094: Вход в проект по задаче, а не по всему архиву

- **Статус:** принято (2026-11-26)
- **Уточняет:** R-19; не меняет критерии переноса R-07…R-10, R-16…R-18

## Контекст

Прежний `AGENTS.md` требовал читать девять документов целиком, даже для локальной
правки. Это загружало в контекст историю чужих механик и не отвечало на первый
вопрос: какой из двух путей запуска обслуживает текущую панель Godot?

## Решение

1. `AGENTS.md` остаётся обязательной стартовой страницей: правила, карта запуска
   и входы в документы по задаче. Перед правкой прочитать относящиеся к ней
   разделы `RULES.md` и лист механики. Для возобновления прежней работы открыть
   актуальную строку `PROGRESS.md` и последнюю относящуюся к ней запись `WORKLOG.md`.
2. Только для **переноса с эталона** выполнять весь существующий цикл: взять
   назначенную механику (или первую незавершённую при продолжении плана), сверить
   карту кода, статус и судьбу её тестов, затем корпус, контракт, код, `selfcheck`
   и живой прогон. Явная задача пользователя не переключается на другую механику.
3. Карта запуска отделяет установленную панель, HTTP-сервер и его адаптеры от
   модульного моста редактора. Нативные пины и исторические тесты не ослабляются:
   новое поведение размещается в поддерживаемой обёртке и описывается в журнале
   отклонений. Этот ADR не переключает `plugin.cfg` или профиль сервера.

## Последствия

Меньше обязательного чтения для локальных правок. Все правила, требования к
записи/безопасности и проверки перед отчётом остаются в силе. Статусы `ported`
и содержимое исторических корпусов не меняются.
