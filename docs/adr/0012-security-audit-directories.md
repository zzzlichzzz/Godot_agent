# ADR-0012: security_audit читает файлы, не каталоги с файловым суффиксом

Дата: 2026-10-31. Решение аудитора: C.16, сессия70, §9 (ретро-разрешение F8).

## Контекст

Гейт tools/security_audit.py обходит дерево по суффиксам и читает каждый артефакт.
Фикстуры точного паритета могут содержать каталог с именем *.gd. В частности,
fixtures/projects/corpus/editing/split_gd_plan/existing_module_dir/editor/part_one.gd
нужен кейсу140: эталон считает уже существующий каталог занятым целевым модулем.
Без фильтра гейт пытается read_bytes() каталога и падает PermissionError.

В C.15 портер добавил минимальный is_file-фильтр после отдельного разрешения
пользователя на S1. Аудитор сессии69 отметил, что §-разрешение и оформление F8
отсутствовали. Сессия70 разрешает оставить существующую строку и закрепить её,
не расширяя правку замороженного гейта.

## Решение

files(base, suffix) отдаёт только обычные файловые артефакты. Существующий фильтр
`if not path.is_file(): continue` выполняется до добавления пути и до чтения.
Каталоги с подходящим суффиксом пропускаются; поведение проверок для файлов
не меняется. Текущий security_audit.py остаётся побайтово неизменным:
10885 B, SHA256 77956be3be9f295b3d4d50de00af16a1051a0745d474f566a44a7c6536115c4d.

## Последствия и доказательства

Гейт не падает на каталоге. Это не сокращение проверок: каталог не является
читаемым проверяемым артефактом; обычные файлы и файловые потомки проверяются.
tests/py/tools/test_security_audit_dirs.py закрепляет files(), полный main()
на временном дереве x.gd/y.gd и точный текст двух строк существующего фильтра.
Удаление фильтра даёт три красных теста, включая PermissionError и exact pin;
возврат исходных байт даёт три зелёных. Старый security-тест продолжает проверять,
что обычный файл с секретом рядом с каталогом обнаруживается.

## Границы

Не менять SKIP_DIRS, сортировку, список суффиксов, набор CHECKS или правила чтения.
Не добавлять отдельную политику симлинков/специальных файлов, is_dir/stat/glob;
существующая семантика is_file не расширяется и гарантия запрета симлинков
этим ADR не заявляется. Другие гейты и write-воронка вне решения.
