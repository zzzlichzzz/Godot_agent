## Решение

1. Native auth bytes unchanged; stricter ProjectAuth authenticates/bounds request
   first, including Host/Origin before health. Native fail-open fallback denied.
2. One Agent and existing B dispatcher/funnel. Channels translate only. Optional
   runtime factory creates structural adapters; bootstrap remains sole module
   registration/composition entry. K1 default gateway/base50/accepted aliases unchanged.
3. Per-session native namespaces/scoped absolute server_state import, profile/API/
   history overrides under existing lock and finally restoration. Control-plane
   stop/progress does not queue behind blocked profile scope. Browser get/wait may
   observe only this session's typed owned facade; no foreign adoption/stealth.
4. Default random owned 127.0.0.1 listener; external nonsecret endpoint inverse
   requires plain same device/inode plus complete original bytes. Native port_guard
   remains reference-only; no unowned termination or borrowed listener.
   Listener finally closes only its session gateway, whose close releases only
   its own typed facade. Injected/no-gateway sessions do not touch global browsers;
   actual fake-listener RED before implementation, no real process termination.
5. MCP executable uses unchanged core/one Agent, newline≤1,000,000, finite JSON,
   depth64 and next-frame recovery. Profile outside project/source before recovery.
   HTTP also rejects agent-source profiles before token IO/adapters. A synthetic
   unread-token spy supplies two own production RED cases without writing source.
6. Separate exact SHA+path native caps: chat_routes1169/SHA91c8a9689096a670d9b514d09c58829d38d294edc8140f43554d98077fdfda0f;
   server_state832/SHAefecb557b45c4a6e0ea4a4b806027cab20f07af8bda6a6e72f3e297575300c1e.
   Mutation/EOL/sibling path revokes allowance. Existing checker maps/default400/
   module3000/area8000/cohesion8400/entry150/150/80 unchanged.
7. Native channel reference corpus has explicit read-only replay lane; it is not
   public assistant success or live verification. Old replay/selector behavior
   stays exact; production routing/checker changes require their own RED.
