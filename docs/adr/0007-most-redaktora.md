# ADR-0007. Мост редактора: кто слушает и как звучит кадр

Статус: принято (2026-10-27). Основание: срез «мост редактора, часть 1» —
нужен протокол между двумя процессами до кода примитивов (R-14, ADR-0003).

## Контекст

В старом агенте слушал **Python**: Flask на `127.0.0.1:5000`, редактор ходил к
нему через `HTTPRequest` (`agent_server_link.gd`). В новом агенте примитивы и
главный поток живут на стороне редактора: сцены, выделение и undo-скоуп
принадлежат ему. Плюс старый агент оставлял процесс-сироту, держащий порт, если
редактор закрывался первым.

## Варианты

| Кто слушает | Плюсы | Минусы |
|---|---|---|
| **GDScript (редактор)** | владелец ресурса — редактор; нет сироты, держащего порт; Python перезапускается свободно; редактор сам знает, что мост жив | меняет SEC-03 (слушающий сокет вне `channels/http`); нужен файл с портом (`user://godot_agent/port.json`) и токен в кадре |
| Python | SEC-03 не меняется; HTTP-обвязка знакома | процесс-сирота; редактор обязан знать адрес Python; при перезапуске Python мост «висит»; HTTP ради локального кадра — лишний слой |

## Решение

**Слушает GDScript.** Python — клиент (`substrate/editor/client.py`). Обоснование:
редактор владеет ресурсом, его жизненный цикл — источник правды «жив ли мост»;
сироты, держащего порт, не остаётся; Python может перезапускаться без
перезапуска редактора. Цена — SEC-03 меняется осознанно (см. ниже), а не «забыли».

## Кадр

- 4 байта длины (big-endian) + JSON UTF-8; лимит кадра — 1 МиБ;
- первый кадр — handshake:
  `{"hello": {"protocol": 1, "verbs_version": 1, "godot": "4.6",
  "project_hash": "…", "token": "…"}}`;
- несовпадение `verbs_version` → `engine_down/details.reason=verbs_mismatch`;
  чужой `project_hash` → `engine_down/wrong_project`;
- один in-flight на соединение; очередь — в Python-клиенте; второй кадр до
  ответа клиент не отправляет;
- таймаут кадра — настройка профиля, по нему `engine_down/timeout`;
- разрыв посреди кадра → `engine_down/truncated` (не «битый JSON»);
- адрес только `127.0.0.1`, порт случайный, токен в каждом кадре;
  файл `user://godot_agent/port.json` пишет редактор, читает Python.

## Версия словаря

`contract/editor_verbs.json` (`schema_version: 1`, `verbs_version: 3`) версионирован
целиком: `result_schema` каждого примитива — часть контракта, а не комментарий.
Форма элемента `open_scenes` (`path`, `revision`, `dirty`, `active`,
`unsaved_changes`) зафиксирована именно здесь, потому что часть B опирается на
`revision` и `dirty`; имена полей `result_schema.properties` обязаны совпадать со
списком `result`, иначе `tools/gen_contract.py --check` падает.

Политика бампа (тот же текст лежит в `_change_policy` файла словаря):

Добавление примитива — verbs_version + 1, аддитивно: старый клиент продолжает работать, новый клиент на старом сервере получает engine_down/verbs_mismatch. Изменение семантики существующего примитива (значение поля, единицы, момент вызова) — +1, и старый сервер считается несовместимым. Изменение только описаний и схем без изменения поведения — версию не меняем. Правило «добавил примитив — поднял версию» машинно не проверяется: бамп и запись в ADR обязательны по этой политике.

Журнал бампов:

- `1 → 2` (2026-10-28, часть B моста): добавлены `editor_scene_plan` (dry-run) и
  `editor_scene_apply` (запись одним undo) с `effects: write`, `thread: main` —
  аддитивно, старый клиент на новом сервере получит `engine_down/verbs_mismatch`.
  `protocol` остался `1`: форма кадра и handshake не менялись. Зашитые места версии:
  `editor/bridge/server/session.gd`, `editor/bridge/verbs/editors/editor_verbs.gd`,
  `editor/bridge/server/socket_server.gd` (`port.json`), `tests/py/integration/fake_editor.py`
  (`PING` и дефолт `__init__`), `tests/py/integration/test_editor_context_bridge.py`.
- `2 → 3` (2026-10-29, часть B.3 моста): добавлен `editor_scene_undo` (откат истории как
  примитив: `effects: write`, `thread: main`, вход `{scene, expected_revision}`, выход
  `{revision, undone, undo_label, history_version_before, history_version}`) — аддитивно,
  `protocol` остался `1`. Причина бампа: откат истории нужен модели как примитив, а не
  только как побочный эффект `editor_scene_apply`; `history_version*` — версия
  `UndoRedo.get_version()` (растёт на 1 за действие, убывает на 1 за откат), потому что
  `get_history_count()` после отката не меняется (redo-стек). Те же шесть зашитых мест
  версии, что у `1 → 2`.

## Последствия

- `docs/security/invariants.md` SEC-03 переписан: слушающий сокет моста —
  `editor/` (GDScript) на `127.0.0.1`, Python только клиент; второй слушающий
  сокет запрещён.
- Q-02 («кто запускает процесс») закрывается для этого моста: запускает
  редактор, Python подключается по `port.json`; для HTTP-канала вопрос остаётся.
- Словарь примитивов версионирован (`contract/editor_verbs.json`,
  `verbs_version: 2`); расхождение версий — `engine_down`, а не тихое «работает».
- Часть B добавила запись в сцену: `editor_scene_plan` ничего не пишет, `editor_scene_apply`
  правит открытую сцену **одним** undo (`UndoRedo.create_action` → `commit_action`,
  при провале `cancel_action`), `ResourceSaver` не вызывается — файл `.tscn` на диск
  пишет часть C.

## Что этот ADR не решает

- запись в сцену и undo-скоуп — часть B (`editing.scene_ops`);
- `.tscn`/`.tres` как файлы — часть C;
- автозапуск Python из редактора (Q-02 для остальных каналов) — отдельный срез.
