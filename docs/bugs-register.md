# Реестр багов Godot Agent

## Проверенные исправления

| Баг | Исправление и проверка |
|---|---|
| BUG-001: конфликт эксклюзивных окон | Диалоги выбора модели и удаления чата не запрашивают эксклюзивность. В изолированном Godot 4.6.3 проверены одновременное открытие с эксклюзивным окном и пересборка стартового экрана без предупреждения `exclusive child`. |
| BUG-002: `Parameter "obj" is null` | Подписки отключаются при выходе узла из дерева и не обращаются к уже освобождённому источнику. Godot-тест проверяет отсоединение и повторное добавление узла, освобождение источника и выгрузку плагина. |
| BUG-003: повторный вход `agent_entry.gd` | Только один экземпляр владеет доком и интеграциями. Godot-тест проверяет повторный вход того же экземпляра, отказ второго и штатное восстановление после выгрузки. |
| BUG-007: расхождение UID фикстур | Согласованы исходный корпус C.21 и семь уже закреплённых UID ревизии D103 без удаления файлов и изменения эталонных ответов. Импорт в Godot не изменил байты копии корпуса под `fixtures/.gdignore`, при этом новый скрипт вне fixtures получил UID. Историческая причина отсутствия 181 UID в отдельном снимке D105 не установлена; тот снимок не изменялся. |
| BUG-014: первый `POST /chat` возвращал `400` с исчерпанием шагов | Завершённый обычный ответ больше не требует повторов только из-за отсутствия DONE; ошибка доставки возвращается сразу. `chat_id` и `editor_context` действуют только в текущем запросе. Структурное действие проходит проверку и preview без записи. 10 сценариев на HTTP-композиции с подменой транспорта прошли; реальный DeepSeek в этом прогоне не проверялся. |

Повторный широкий прогон до D117, без `tests/py/live`: 8643 passed, 2 skipped, без падений. Изолированный тест Godot выполнен отдельно. Тесты и способ проверки: [T1-editor](porting/T1-editor.md), [editing.paths_preview](porting/editing.paths_preview.md), [assistant.write](porting/assistant.write.md).

**D117 — продолжение BUG-014 по живому отчёту:** длинный служебный промпт мог стать `.txt`, а повторное заполнение — добавить второй файл до отправки пользовательского текста. DeepSeek теперь использует прямое текстовое заполнение и один Enter на сообщение; при неясной доставке не повторяет отправку и не перезаписывает черновик зеркалом. Проверены сохранение имеющихся вложений, отказ на чужой вкладке и раздельная отправка промпта и «привет» в изолированной форме. 165 целевых тестов прошли, включая восстановленный порядок отказов живого ввода в API-чате. Проверка на реальном DeepSeek ещё предстоит.

**D118 — новый живой отчёт:** `textarea#chat-input` не подходил к актуальной форме `textarea[name="search"]`. Отправка и зеркало теперь используют одну проверку активного поля; поле редактирования и неоднозначный DOM не принимаются. Отказ до записи больше не оставляет зеркало заблокированным. 166 целевых тестов и проверка локальной формы в Chrome прошли; проверенная сборка установлена. Пользователь подтвердил живую отправку и получение ответа; зеркало отдельно не подтверждено.
