# Принятые отклонения

Эталонные ответы и пины не обновляются автоматически при расхождении. Для намеренного изменения указывайте область, прежнее и новое наблюдаемое поведение, причину и ссылку на решение и проверку (R-06/R-09). Для обычного исправления достаточно регрессионного случая и коммита, если контракт не меняется.

- **Лимиты размеров (D18 и последующие уточнения).** Для области 8001–8400 строк — предупреждение, выше — ошибка. Пределы файлов, исключения для перенесённых реализаций и проверку хешей определяет [`tools/check_limits.py`](../tools/check_limits.py). Исключение действует только для указанных в проверке файлов или каталогов.
- **Структурные правки.** Отказ загружать скриптовую цель, её небезопасную зависимость или autoload во временном проекте — граница исполнения, а не повод включать пользовательский код ради паритета. См. `SEC-T1-OVERLAY` в [инвариантах](security/invariants.md).
- **Браузерный Kimi.** По запросу пользователя новые чаты открываются на `https://www.kimi.ai/?chat_enter_method=new_chat` вместо `https://www.kimi.com/`. Сохранённая ссылка на беседу остаётся на своём домене: одинаковый ID на другом домене не подтверждает чат. [Проверка открытия и привязки в Chrome](../tests/py/live/test_provider_navigation.py).

Первичные решения и история отклонений доступны без пересказа: [ранний реестр](https://github.com/zzzlichzzz/Godot_agent/blob/e0e0758bd58da147c0f8eca818fde26f3514fcca/docs/deviations.md) и [продолжение от D90](https://github.com/zzzlichzzz/Godot_agent/blob/e0e0758bd58da147c0f8eca818fde26f3514fcca/docs/porting/deviations.md). Для конкретного исключения ищите его номер в этих снимках.
