# Диагностика панели

## Сервер не запускается

1. Проверьте, что рядом с `res://addons/godot_agent/plugin.cfg` есть `python/dist/godot_agent_server.exe`. В копии из Git его нужно [собрать](../README.md#установка-из-исходников-на-windows).
2. Запустите из панели: она передаёт путь к **этому** редактору даже без Godot в `PATH`. При прямом запуске EXE без аргументов важны путь установки и сохранённая привязка к проекту. Если редактор переместили, снова запустите сервер из панели.
3. В **Проект → Открыть папку пользовательских данных** (`user://`) найдите `http_endpoint.json`. [Запрос `/init`](clients.md#http-уже-запущенного-дока) должен вернуть корень текущей игры. Если порт 5000 занят другим проектом, сначала штатно остановите его сервер. Не удаляйте токен у работающего процесса.

## Страница чата не загрузилась

- Если ещё виден экран ожидания, нажмите **Меню**. Можно снова выбрать сайт или сохранённый чат; запоздалый ответ не откроет чат поверх меню.
- Если чат уже открыт, нажмите **↻** рядом с **Меню**. Перезагрузится вкладка выбранного чата; черновик в Godot и ожидающее подтверждение сохранятся. Отправка — только по кнопке **Отправить**. Уведомление о готовности появится, когда на нужной странице будет доступно поле ввода.
- Если после перезагрузки Arena показывает диалог (например, о cookies), сделайте выбор на вкладке сайта. Панель дождётся поля ввода. При включённом живом вводе следующее изменение черновика снова появится на сайте; сама перезагрузка ничего не вставляет.
- Если вкладка Arena уже закрыта, выберите **Меню → Новый чат → Arena**. Агент откроет новую вкладку, сохранив остальные. Если закрыто всё окно агента, он запустит его заново.

## Проверка ввода на сайте

- Чтобы черновик оставался в Godot, выключите «⌨ Живой ввод в браузер» в дополнительных настройках панели. Выбор сохраняется. Кнопка «Отправить» по-прежнему запускает ход агента; ввод на самом сайте обратно в панель не переносится.
- **Arena Direct и Battle:** на выбранной вкладке закройте диалог сайта, если он перекрывает чат. Наберите в панели две строки, затем удалите вторую. Черновик на сайте должен повторить оба изменения; до нажатия «Отправить» сообщение не появляется в истории.
- **После ошибки Arena:** текст остаётся в панели. Браузер не должен сам очищать поле, вставлять текст снова или отправлять его. Если панель говорит «сообщение не отправлено», исправьте черновик и нажмите «Отправить» один раз. Если говорит «отправка не подтверждена», сначала посмотрите, не появилось ли сообщение на сайте. Код с табуляцией и большие вставки можно отправлять целиком: такой черновик остаётся в панели до отправки.
- **Kimi:** при первом сообщении сайт может превратить текст с инструкциями агента во вложение. Для запроса `привет` ожидается один файл и подпись `привет`, без дописанного пояснения. Для длинного или многострочного запроса достаточно самого файла. Перегрузка сайта — отдельная причина отсутствия ответа.

## Ответ завис или результат не совпал с сообщением модели

В `user://agent_chats.json` хранится диалог. Для записи отдельно проверьте предпросмотр, квитанцию и состояние файла: сообщение модели не подтверждает применение. В `user://agent_turn_timings.json` хранятся времена **последних 64 ходов**, включая продолжения после разрешённого чтения. Если задержка повторилась, запишите примерное время и что показала панель.

| Поле | Что оно показывает |
|---|---|
| `utc_s` | Начало хода, Unix-время UTC в секундах |
| `first_text_ms`, `visible_done_ms` | Когда сервер впервые увидел текст и конечную строку `===DONE===` в потоке |
| `verify_ms`, `total_ms` | Когда началась проверка и когда диспетчер получил итог. Все времена в миллисекундах от начала хода |
| `kind`, `outcome`, `chars` | Тип запроса (например, продолжение чтения или отчёт о переименовании), исход хода, наибольшее число символов по данным наблюдателя |
| `read_tool`, `read_results` | Только для выполненного запроса чтения: инструмент и упорядоченные метки (`empty` — пустая страница, `truncated` — есть продолжение, `directory` — передан каталог, `missing_names` — есть ненайденные имена) |
| `arena_posts` | По одному счётчику на отправку агента внутри этого хода: сколько исходящих POST к потоку ответов увидел монитор Arena. Например, `[2]` — одна отправка; Battle может открыть по потоку для A и B. `null` — счётчик недоступен. Сюда не входят ввод черновика, проверка сайта и прочий трафик страницы. |
| `arena` | Завершённые решения по порядку: `mode` (`direct`/`battle`), число `variants`, результат `decision`. `single` — пришёл один ответ, сравнивать нечего; `selected` — выбор зафиксирован; `local` — только локальный выбор без голоса. При сравнении указаны ветка `selected`, оценки `score_a`, `score_b` и причина. `skip` и `third` различают запрос и получение дополнительного ответа; `failed` — выбор не зафиксирован, `rejected` — ответ отклонён. Отсутствие поля у старой записи ничего не говорит о работе судьи. |

Для ответа с замеченным маркером `total_ms − visible_done_ms` показывает время от наблюдения маркера до завершения диспетчера. Отрисовка Godot и момент, когда пользователь увидел ответ на сайте, сюда не входят. `null` означает «не наблюдалось»: у API нет этих браузерных событий, а окно наблюдения потока ограничено. Это не доказательство, что модель пропустила маркер.

Журнал хранится локально, отдельно от сохранённых чатов. Тексты, содержимое файлов, их пути, адреса, идентификаторы чатов, ключи и аргументы действий в него не попадают.

Для короткой проверки переименования в Arena укажите одну функцию, новое имя и путь к объявлению. Попросите один `analyze_rename` и, если результат допускает, предпросмотр `rename_symbol`. Первое — чтение, второе должно дать карточку подтверждения. Отказ от предпросмотра оставляет файлы без изменений. При двух вариантах сверьте A/B в панели и на сайте; при одном варианте оценки A/B не показываются.

При разборе `ask_librarian` смотри `read_tool: "ask"`. До D127 успешный текстовый ответ мог получить метку `error`; для такого старого хода сверь результат с сохранённым диалогом. Начиная с D127 непустой текст отмечается `ok`, пустой — `empty`. Старые записи не переписываются.
