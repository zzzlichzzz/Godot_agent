## §2 Контракт правки

**2.1. Что делает эталон (читать дословно, не пересказывать).**
`prepare_file_rename(project_root, old, new, update_references=True, allow_addons=False, allow_self_edit=False, addon_dir=None)`:
нормализация обоих путей → отказ при совпадении (`Новый путь совпадает со старым: …`)
→ резолв обоих → **каталог** уходит в `prepare_directory_relocation` → нет
источника (`Исходный файл не найден: …`) → цель существует, кроме case-only
(`Целевой файл уже существует: …`) → политика записи для **обоих** путей
(`Путь защищён текущей политикой доступа: …`) → запрет `project.godot`
(`Нельзя переименовывать project.godot`) → запрет прямого переноса `.import`
и `.uid` при живом источнике → сбор ссылок `find_file_references` →
проекция `update_internal_relative_paths` → подготовленный словарь (**точные
ключи выяснить probe-ом, не выдумывать**).

`apply_prepared_file_rename`: пустая транзакция → отказ; для каждой операции:
источник исчез (`Исходный файл больше не существует: …`), источник изменился
(`Исходный файл изменился: …`), цель появилась (`Целевой файл уже появился: …`),
файл со ссылками удалён или изменился — всё до первой записи; затем перенос и
запись обновлённых файлов.

**2.2. Инварианты порта.**
Только воронка ADR-0005/0015: `Step → WritePlan → durable WAL → Receipt`, квитанция
на каждый эффект до следующего шага, откат в обратном порядке, recovery после
падения. Никакого прямого `open`/`os.replace` из модуля — IO только в `substrate/fs`,
`domain` чистый, `app.py` ≤ 80 строк без импорта substrate. Байты переносимого
файла не пересобираются: перенос — это перенос, а не «прочитать текст и записать».

**2.3. Главный открытый вопрос — операция переноса (см. §10, вопрос 1).**
В воронке сегодня есть только `script_edit`, `create`, `delete`. Перенос файла
невыразим ни одним из них без потери байтов и атомарности. До ответа аудитора
**ни одна строка production не пишется**.

**2.4. Ничего не изобретать.** Где mapping и эталон расходятся — это стоп-условие,
а не повод «сделать логичнее». Где паритет недостижим без нарушения R-15 или
детерминизма тестов — это явное отклонение, которое аудитор вносит в лист
отдельным пунктом.
