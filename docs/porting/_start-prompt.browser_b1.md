## Разрешения, выданные заранее аудитором

1. `substrate/llm/browser` может импортировать selenium и stdlib (это реализация
   порта). Если `lint_arch` падает на стороннем импорте — стоп-вопрос, не правка
   линтера.
2. `contract/browser_stealth.json` в `contract/` вне `capabilities/` разрешён;
   `gen_contract --check` обязан остаться зелёным без правок `gen_contract`.
   Конфликт — стоп-вопрос.
3. Замена байтов разрешена только `browser_manager.py` и `cdp_ws.py`.
4. Живая проверка B-1: запуск реального Chrome с `--remote-debugging-port=9222`
   и отдельным профилем `%LOCALAPPDATA%\Godot_AI_Profile`, свёрнутое окно без
   захвата фокуса (`STARTUPINFO` + `SW_SHOWMINNOACTIVE`), проверки: webdriver
   честно `false`, вкладки создаются/закрываются в своём окне, профиль
   пользователя не затронут, процесс убит после прогона, декоративный спуф не
   зарегистрирован (`Page.addScriptToEvaluateOnNewDocument` — только по флагу
   сайта с доказательством + запись в `deviations.md`). Живой запуск на реальном
   сайте — не в B-1. Это условие DoD: базис без живого прогона непроверяем.

худеет запретом).
