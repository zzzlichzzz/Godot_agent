## §2 Контракт правки

2.1. Что делает механика (читать эталон дословно и снимать поведение прогоном):

  текст получается, какие пути не трогаются, что считается «внутренним».

2.2. Ключевые инварианты среза:

- инструменты **только читают**: `effects="read"`, `idempotent=True`, никакой
  записи, никакого плана, никакого журнала;

  прямое `open()`/`os.walk` в production-коде модуля запрещено (R-12, как в

- границы: `addons/`, `plugin.cfg`, выход за проект — по тому же
