«Пила» для `.gd` (13.10.2026, ветка development): `python/godot_tools/
split_gd.py` — тот же порядок `scan`/`plan`/`apply`, но модель другая. Тело

как `static func name(panel, <параметры>)`: обращение к членам донора —
`panel.<член>`, к другим его методам — `panel.<метод>` (через обёртку),
`$Путь`/`%Уникальный` → `panel.get_node(...)`, константы копируются в модуль.
В доноре на месте метода остаётся тонкая обёртка с исходной сигнатурой:
`connect()` по именам, вызовы из других файлов (`open_safe_rename`,
`handle_filesystem_move`) и движковые виртуальные точки входа продолжают
работать; `.tscn` не правится. Особенности GDScript, найденные обкаткой:
(1) жёсткий `res://`-путь в preload ломал копии аддона в live-тестах —
константы-модули грузятся относительным путём (`preload("agent_panel_part1.gd")`,
файлы лежат рядом с донором); (2) вывод типа `:=` от `panel.<метод>()`
невозможен («Cannot infer the type») — пила понижает `:=` до `=`
у всех var, чьё выражение транзитивно содержит `panel`; (3) движковые
виртуальные методы (`_ready`, `_exit_tree`) и `_process` не выносятся;
(4) `await` в теле сохраняется в обёртке (`return await Module.f(self, ...)`).

относительный preload. Долг v1: донор 1895 всё ещё > warn 1500 (следующий шаг

Вынос методов `.gd` (`agent_panel.gd` и др.) остаётся долгом — решение

Найденные дубли (инвентарь 13.10.2026, `python -B tools/arch_audit.py`):

- `format_report` — ядро `runtime_checks.py` ↔ `server/log_reader.py`;

Разбор 13.10.2026 (вопрос владельца: «слить или оставить исключением?»):

именами** у потребителей — `log_reader.format_log_report`,
`editor_context.normalize_editor_snapshot` / `format_editor_snapshot`
(ядро не тронуто, поведение не менялось; тесты обновлены в том же коммите).

   сводка внутри воркфлоу невозможна (usage моделей-суб-нод попадает в базу
   только после завершения исполнения; каналы — отдельные исполнения), поэтому
   сводка пост-прогонная: по событию `kind=done` сервер рук (:8010) запускает

   `kind=tokens` (вызовы, est prompt/completion, топ-5 моделей). Живой тест:
   прогон 103 — 127 вызовов, est prompt ~3,88 М + completion ~256 К.
   Активация хука — после перезапуска сервера рук; выключатель —
   `N8N_HANDS_NO_TOKEN_HOOK=1`; fallback остаётся — `token_report.py` вручную.
3. **Baseline тестов (дельта до/после).** Владелец: «если улучшит
