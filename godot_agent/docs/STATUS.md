## 1. Архитектура в 10 строк

Одно правило: **функция агента живёт в ядре; всё остальное — проводка.**

| Слой | Где | Роль |
|---|---|---|
| Ядро | `python/godot_tools/` | вся функциональность (+ тест в `python/tests/`) |
| Панель/редактор | `agent_*.gd`, `agent_panel.tscn` | UI; действия исполняют `agent_*_executor.gd` |
| Сервер панели | `python/main.py` (:5000, 38 роутов) | оркестрация, роуты для панели и браузерного чата |
| Браузер | `python/browser/`, `backends/browser_backend.py` | водит Chrome по сайтам |
| API-слой | `python/api/`, `backends/api_backend.py` | провайдеры, ключи, каталог моделей |
| Парсеры | `python/parsers/` | разбор ответов сайтов |
| Мосты | `python/tools/agent_bridge.py`, `godot_agent_mcp.py` | CLI и MCP :8000; единственный источник истины по доступу и записи |
| n8n-фабрика | `n8n/` (вне процесса агента) | 4 канала: Браузер, API, Редактор, MCP |
| ML-подсистема | `python/minilich/` | индексатор проекта, тренер, фиксер сцен |

- Панель → `main.py` :5000 → ядро → файлы проекта.

  `--profile agent-dev` — запись) → `agent_bridge.py` → ядро. Запись
  двухфазная: `write preview` → `plan_id` → `write apply`.
- «Руки» :8010 — сервер инструментов среды; в аддон не входит.

1. **Ядро** — `python/godot_tools/<модуль>.py` + тест в `python/tests/`.

3. **MCP** — `@server.tool` в `python/tools/godot_agent_mcp.py` (пилы и запись —

5. **Панель UI** — карточка/диалог в `agent_*.gd` + константа `URL_*`
   в `agent_server.gd`.
6. **Модель (чат)** — пункт в списке возможностей `python/server/agent_prompts.py`
   + обработка `{"action": ...}`.
