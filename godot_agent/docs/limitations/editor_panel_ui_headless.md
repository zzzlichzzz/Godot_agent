Ниже — обходные прогоны. Они **компенсируют** отсутствие живого UI-клика, но
не заменяют его: ни один не проходит полный путь «галочки панели → UI-клик →
`/chat/confirm_action`» внутри интерактивного редактора.

   → **rc=0, «ИТОГО: 109/109»** (прогон 2026-10-12, локальная проверка).
2. Godot-проверка `agent_panel.gd` (headless): **5/5 без ошибок**
   (локальная проверка 2026-10-12).
3. Статический разбор кода пути «снятие галочки → exclude → применение»
   (выполнен силами конвейера; тоже компенсация, не независимое доказательство):
   - `agent_panel.gd:1562` — чеклист «Места переименования…»; id места = адрес для exclude;
   - `agent_panel.gd:1614-1617` — чтение `_rename_excluded` до сброса состояния;
   - `agent_panel.gd:1651-1656` — передача `body["exclude"]` в confirm-запрос;
   - `main.py:587-616` — формирование id мест (`path:line:column`), они же уходят в `_with_exclude`;

и рендер чеклиста **внутри живого UI редактора** не прогонялись.

## Требование к стенду: перезапуск редактора после обновления панели

`agent_panel.gd` исполняется внутри запущенного Godot-редактора. После
обновления файла панели на диске уже открытый редактор продолжает работать
со **старой** версией скрипта. Любая живая UI-проверка панели допустима
только после **перезапуска редактора**; без него результат не относится
к новой версии панели.

## Что это значит для п.4 задачи

Прогон «rename константы обновляет использование в том же файле» подтверждён
живым HTTP-прогоном (раздел выше) плюс компенсационными проверками (по
отдельности не являются независимыми доказательствами):

- **API** (компенсация): `POST /chat` → `POST /chat/confirm_action`, rc=200, обе строки
  (19 объявление, 69 использование) переименованы, `reference_count=1`; скрипт
  `%TEMP%\n8n_hands_scratch\lab_rename_http_proof.py`, `LAB_HTTP_PROOF: PASS`;
- **MCP-мост** (компенсация): `agent_bridge.py write preview` → `write apply` → `write rollback`, rc=0,
  в диффе ровно два ханка (`@@ -16,7` и `@@ -66,7`), цикл rename→rollback→rename чист;
- **Браузер** (компенсация): `probe_rename_turret.py` (rc=0) на temp-копии проекта:
  вызовы `/chat` (rc=200) и `/chat/confirm_action` (rc=200, варианты (a) без exclude
  и (b) с exclude) — строки 19/69 обновляются вместе в (a); в (b) снятое место
  остаётся старым осознанно (`skipped_usages`).

Панель редактора использует те же `/chat` и `/chat/confirm_action`
(wiring-тест, 109/109), а её эксклюзивный участок — рендер чеклиста и сбор
`exclude` — покрыт wiring-тестом и статическим разбором кода; живой UI-клик
в headless недоступен и заменён этим документом плюс живым HTTP-прогоном.
