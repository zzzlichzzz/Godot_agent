## 🔧 Ревизия визуала (10.08.2026)

Проверены все визуальные скрипты и сцены. Плагин **не компилировался**: `agent_panel.gd` и
`agent_chat_view.gd` падали с `Compile Error: Failed to compile depended scripts`. Исправлено
только оформление — сеть, транспорт и бизнес-логика не тронуты.

**Блокеры компиляции (37 Parse Errors):**
- `get_theme_color(...) or Color(...)` — оператор `or` возвращает `bool`, а не `Color`. Заменено
  на хелперы `_tc/_tf/_tfs/_ti` с проверкой `has_theme_*` (заодно ушёл спам ошибок темы).
- `get_theme_color(name, type, {"disabled": true})` — у метода максимум 2 аргумента.
- `TextureRect.EXPAND_KEEP_SIZE_CENTERED` — такого члена нет (это `stretch_mode`).
- `Time.get_time_dict()` — нет в Godot 4, нужен `Time.get_time_dict_from_system()`.

**Верстка (.tscn):**
- Ко всем сценам карточек не был подключён `script` — узлы инстанцировались «пустыми».
- `anchors_preset`/`anchor_*`/`layout_mode = 1` внутри контейнеров: якоря игнорируются
  контейнером и ломают расчёт размера. Везде `layout_mode = 2`.
- `theme_override_constants = { "margin_*" }` у `PanelContainer`/`HBoxContainer` — margin-константы
  есть только у `MarginContainer`. Отступы перенесены в `content_margin_*` у `StyleBoxFlat`.
- Godot-3 свойство `margin_left` в `AgentMessageCard.tscn`.
- У `ToolCallCard` было два контейнера-потомка `PanelContainer` — они накладывались друг на друга.
  Добавлена обёртка `RootVBox`.
- `RichTextLabel` без `fit_content` внутри контейнера получал нулевую высоту — текст сообщений,
  параметров инструментов и блоков кода был не виден.

**Логика отображения:**
- `feed_live_stream` вставлял текст мгновенно, таймер «плавной печати» не запускался никогда.
  Теперь стрим идёт через буфер печати.
- Ответ, уже «напечатанный» стримом, дублировался финальным `add_agent_message` — теперь
  переиспользуется живая карточка.
- `setup()` не удалял старый `ChatScroll` (условие `child is RichTextLabel` не пропускало
  `ScrollContainer`) — при переоткрытии дока появлялся второй чат.
- `show_status_bar` создавал новый статус-бар на каждый вызов; старый ещё не был освобождён,
  Godot давал новому имя `AgentStatusBar2`, и `update/hide` его больше не находили. Статус-бар
  теперь один и закреплён под списком карточек (не уезжает при скролле).
- `_scroll_to_bottom` брал `max_value` до пересчёта размеров и выдёргивал скролл, даже когда
  пользователь листал историю вверх.
- `ToolCallCard`: `get_theme_icon(...) != null and "📁" or "📄"` подставлял в заголовок `True`/`False`;
  `Button.icon_rotation` не существует. Иконка вынесена в отдельный `TextureRect`, стрелка тоггла —
  две разные иконки темы.
- Fallback `XxxCard.new()` при неудачной загрузке сцены создавал узел без дочерних нод — первый же
  `@onready` падал с null. Теперь честный `null` и текстовый запасной вариант.
- Кнопки подтверждения и «Применить/Отклонить» блокируются после клика (защита от двойной отправки).

**Проверено:** `Godot v4.6 --headless --editor` — 0 ошибок скриптов; временные selfcheck-прогоны
карточек и `agent_chat_view` (46 проверок) пройдены и удалены.

## 🩹 Правки по замечаниям (10.08.2026, вторая итерация)

**1. Текст «прыгал» при наведении.** Кнопка «Копировать» лежала в отдельном блоке `Actions`
под текстом и появлялась через `visible`, из-за чего карточка меняла высоту прямо под курсором.
Кнопки перенесены в шапку карточки и больше не скрываются через `visible` — прячутся
прозрачностью (`modulate.a`) с `MOUSE_FILTER_IGNORE`. Место зарезервировано всегда, размер
пузыря при наведении не меняется (проверено: 167.0 → 167.0 px у пользователя, 74.0 → 74.0 px
по высоте у агента).

**2. Облачко пользователя центрировало текст.** Пузырь занимал всю ширину строки, а `Label`
внутри был выровнен по центру. Теперь:
- Внешняя карточка прозрачная (`StyleBoxEmpty`), фон рисует вложенный `Bubble`.
- `Bubble` имеет `size_flags_horizontal = SIZE_SHRINK_END` — реально прижат к правому краю.
- Ширина считается по самой длинной строке текста (`_recalc_bubble_width`) с потолком
  `MAX_WIDTH_RATIO = 0.78` от ширины панели: короткие сообщения обжимаются, длинные переносятся
  по словам и не растягиваются на весь чат.

**3. Подтверждение дублировалось в чате и в интерфейсе.** `PendingActionBox` из
`agent_panel.tscn` показывался одновременно с карточкой. Его нельзя просто удалить: поле
`pending_action_box.visible` используется как **флаг состояния** в пяти местах
(`_on_send_pressed`, `_on_check_log_pressed`, `_on_export_api_pressed`,
`_reconcile_confirm_buttons`, `_send_confirm_request`), а сами кнопки — охранником
`_guard_confirm_buttons`. Поэтому скрыты только его дети (`ActionLabel`, `ConfirmButton`,
`RejectButton`): `HBoxContainer` со скрытыми детьми даёт нулевую высоту и ничего не рисует.
Проверено: высота бокса 31.0 → 0.0 px, `visible` остаётся `true`, сигналы кнопок работают.

**4. Новое: «Разрешить всё».** Третья кнопка на карточке подтверждения и на `DiffPreviewCard`.
- Включает режим авто-подтверждения: следующие запросы применяются без карточки, в чат идёт
  строка «Разрешено автоматически: …».
- Пока режим активен, в чате висит баннер с кнопкой «Отключить авто-подтверждение».
- Режим сбрасывается при `clear()` (новый/переключённый чат), чтобы не переносился в другой
  контекст молча.
- Бизнес-логика не тронута: карточка по-прежнему дёргает те же `_on_confirm_pressed` /
  `_on_reject_pressed`, просто без ожидания клика.

**Проверено:** `--headless --editor` — 0 ошибок; selfcheck правок (23 проверки: hover без
сдвига, выравнивание и обжатие пузыря, три кнопки, авто-режим вкл/выкл/сброс, авто-применение
диффа) и selfcheck `PendingActionBox` (7 проверок) пройдены, файлы тестов удалены.
