## Инструкция по установке

(Важно чтобы был установлен "Google Chrome")

1. Просто кидаешь в папку в годоте res://addons/  (res:// это просто файловая система внутри Godot)

 1.1 Лучше если полный путь аддона будет res://addons/Godot_agent/godot_agent/

2. Далее просто запускаешь плагин Проект -> Настройки Проекта -> Модули -> Godot Agent (поставить галочку)

3. Агент будет находиться справа в последней вкладке

4. Нажимаешь новый чат и идет подключение к локальному серверу

4.1  После подключения к серверу появиться браузер

4.2 Браузер и Сервер которые откроются не закрывать, без них работать не будет

5. Нажимаешь на "Google ai studio" и на сайте гугл вводишь логин/пароль (пока не получилось синхронизировать информацию у гугл хрома о пользователе, вероятно получиться в будущих обновлениях)

6. Теперь можно писать запросы , работает как ИИ агент , умеет изменять файлы , создавать новые , перемещать , создавать сразу небольшие игровые механики с одного запроса и даже делать мини игры

А так же сейчас уже имеются всякие функции по коррекции ошибок допущенных нейросетями, лёгкое исправление кода, не пропускает сломанные сцены в движок, в сложных случаях автоматически пишет нейросети какие ошибки были допущены и требует их исправить, есть встроенный библиотекарь чтобы нейросеть могла найти нужный ей скрипт или что либо еще в проекте
