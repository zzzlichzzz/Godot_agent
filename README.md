# 🤖 Godot AI Agent

Автономный ИИ-ассистент внутри редактора **Godot 4**: исследует проект, создаёт и правит сцены, скрипты, ресурсы и настройки, показывает каждый патч в виде диффа и откатывает что угодно в один клик.

Два режима работы: **через браузер** (бесплатно, без API-токенов) и **по API-ключу**.

## 🚀 Установка

1. Скопируйте аддон в проект: `res://addons/Godot_agent/godot_agent/`
2. **Проект → Настройки проекта → Плагины** → включите **Godot Agent**
3. Панель **«ИИ Агент»** появится в правом доке (вкладка автоматически ставится первой)

Требуется **Godot 4.3+** (проверено на 4.6.1) и **Google Chrome** для браузерного режима. Python не нужен: сервер уже собран в `godot_agent_server.exe` и стартует сам на `127.0.0.1:5000`. Кнопка «Открыть папку с exe сервера» и ссылка на [дашборд](http://127.0.0.1:5000/dashboard) есть на стартовом экране и в панели.

**Первый запуск:** «Работа через браузер» → выберите сайт → авторизуйтесь в Chrome → **выберите модель на странице сайта** → пишите в чат (`Ctrl+Enter`).

## 🧠 Два режима работы

### 🌐 Браузерный режим (основной, бесплатный)

Плагин сам водит обычный Chrome по знакомым сайтам: печатает текст в поле ввода, читает поток ответа через CDP и перехват сети, разбирает его в чистый текст. Токены не нужны, окно браузера и консоль сервера закрывать нельзя.

| Сайт | Как читается ответ | Особенности |
|---|---|---|
| **Google AI Studio** | DOM + перехват сети | Gemini с огромным окном контекста на весь проект |
| **Qwen** | SSE-перехват сети + DOM | основной парсер сети, DOM — резерв |
| **Kimi** | Connect-RPC перехват | ответ берётся только из сети |
| **DeepSeek** | DOM | без блока «размышлений» |
| **Arena AI Direct** | стрим Vercel | один конкретный ответ |
| **Arena AI Battle** | стрим + локальный судья | два ответа A/B, плагин проверяет оба линтерами и выбирает прошедший |

Все сайты работают с подменой видимости вкладки, чтобы она выглядела активной. «Добавить свою страницу» — в плане, универсального парсера пока нет.

### 🔑 Режим API-ключа (экспериментальный)

Прямые запросы к провайдеру, браузер не нужен. Ключ хранится **вне папки проекта** (`%APPDATA%\Godot_agent\`), чтобы не попасть в git и в сборку игры.

| Провайдер | Endpoint | Ключ |
|---|---|---|
| OpenRouter (по умолчанию) | `https://openrouter.ai/api/v1` | ✅ |
| Groq, быстрый бесплатный тир | `https://api.groq.com/openai/v1` | ✅ |
| Google Gemini, именно API-хост | `https://generativelanguage.googleapis.com/v1beta/openai` | ✅ |
| Opencode Zen | `https://opencode.ai/zen/v1` | ✅ |
| DeepSeek | `https://api.deepseek.com/v1` | ✅ |
| AgentRouter | `https://agentrouter.org/v1` | ⚠️ недоступен, allow-list клиента |
| Свой OpenAI-совместимый адрес | задаётся вручную | ❌ подходит для Ollama и llama-server |
| + до 166 провайдеров из каталога [models.dev](https://models.dev) | по каталогу | ✅ не включаются без явного разрешения |

* **Несколько ключей на провайдера** с авторотацией: кончился лимит — агент сам перейдёт на следующий. Исчерпанные ключи помечаются и не пробуются снова, пока не нажать «Пробовать заново». Поддерживаются переменные окружения `GODOT_AGENT_<PROVIDER>_KEY`.
* **Каталог моделей** подтягивает цены, окно контекста, флаги бесплатности, `beta` и `deprecated`. Живой ответ провайдера всегда важнее каталога.
* **Прокси** (http/https с логином и паролем, SOCKS не поддерживается) и **DoH** (по умолчанию `https://xbox-dns.ru/dns-query`) — на случай блокировок. Локальные адреса всегда идут напрямую.
* Модель закреплена за чатом, «Продолжить на этой модели» переносит открытый чат на другую без потери переписки.
* ⚠️ Код проекта уходит на серверы провайдера, на бесплатных тарифах он может использоваться для обучения моделей.

## 🛠 Что умеет агент

| Область | Возможности |
|---|---|
| **Чтение** | `read_file` до 5 файлов за раз, `read_function` только нужные функции, `search_project`, `list_files`, `list_scene`, `ask_librarian` (Библиотекарь), `gather_context` (сводный пакет: символы, сцена, зависимости, диагностика, ClassDB, autoload, InputMap) |
| **Файлы** | `create_file` многочастевой до 8 частей, `patch_file`, `move_file`, `copy_file`, `rename_file` с обновлением всех ссылок, `transaction` до 30 операций всё-или-ничего |
| **Планы** | `plan` — пошаговый чек-лист с подтверждением и прогрессом «Шаг N/M», до 12 шагов (30 суммарно), остановка и откат цепочкой |
| **Рефакторинг** | `rename_symbol` безопасно для `class_name`, функций, сигналов и переменных, `rename_node`, `reparent_node`, `delete_node` с чисткой сигналов и NodePath |
| **Сцены** | `create_scene` и `edit_scene` через настоящий API движка: `add_node`, `set_node_property`, `attach_script`, `connect_signal`, `reparent_node`, `remove_node`, `set_owner`. Только PackedScene — никаких правок сырого `.tscn` и сломанных UID |
| **Ресурсы** | `edit_resource` для `.tres` через ResourceLoader: свойства, ссылки, value-треки Animation, SpriteFrames, Theme, TileSet atlas source |
| **project.godot** | `edit_project_settings`: Input Actions и Input Events, Autoload (добавить и убрать), главная сцена, имена слоёв, параметры отображения |
| **Библиотекарь** | Локальный семантический индекс GDScript: объявления, ссылки, хэш свежести. Поиск по символам, сценам, узлам, сигналам и классам ClassDB. Работает офлайн и не засоряет контекст модели |
| **Справочник API движка** | Кнопка `📡` выгружает реальный ClassDB вашей версии Godot, код модели сверяется с настоящими сигнатурами, а не с памятью модели |
| **Runtime-инспекция** | `inspect_runtime` — read-only срез живой debug-сессии: активная сцена, дерево, свойства, ошибки, метрики, события |
| **Разбор ошибок** | Автодетект старта и остановки игры, чтение лога и отправка ошибок движка модели одним кликом |
| **Удобные команды** | `project_command`: типизированные шорткаты `create_scene_component`, `create_input_action`, `register_autoload`, `rename_symbol`, `atomic_files` |
| **Самовосстановление** | Невалидный JSON, сломанный план или провал линтера — до 3 автоматических повторов с точной причиной, для плана переспрашивается только сломанный шаг |

Акции передаются текстом в блоке ` ```agent_action `, нативный function calling не используется, поэтому протокол работает одинаково на любой модели.

## 🛡 Безопасность, валидация и откат

* **Подтверждение каждого действия.** Карточка «Разрешить / Отклонить / Разрешить всё» перед применением. Авто-подтверждение включается кнопкой и гасится одним кликом, на вопросы модели оно никогда не действует.
* **Diff Preview.** Цветной дифф в чате: свёрнутый заголовок `путь +N -M`, полный просмотр, «Применить» и «Отклонить».
* **Три барьера проверки** перед записью: текстовые линтеры `gd_lint`, `gd_api_check` и `tscn_lint`, затем изолированная проверка кандидата настоящим Godot в headless-режиме, затем сверка семантического хэша результата с тем, что вы одобрили. Исполнители на GDScript работают только на главном потоке редактора, Python никогда не трогает PackedScene, ProjectSettings и ResourceSaver.
* **Журнал и откат.** Каждое изменение пишется в `.agent_history` (снапшоты, журнал, цепочки планов). Кнопка отката висит на карточке сообщения, принудительный откат требует двойного подтверждения.
* **Политика доступа.** По умолчанию агент изолирован от `res://addons/` и от файлов самого плагина. Разрешение выдаётся в настройках и **само сбрасывается при перезапуске редактора**, на self-edit требуется повторное подтверждение.
* **Безопасное переименование** включено по умолчанию: переименование файла или узла прямо в редакторе само обновляет `preload`, `load`, `extends`, `ext_resource`, иерархию, сигналы, треки анимации и `$Node`, `%Unique`, `get_node()` в прикреплённых скриптах. Отдельно доступно из меню **Проект → Инструменты**.

## 🖥 Интерфейс

**Стартовый экран:** три входа — «Загрузиться» сохранённые чаты, «Работа через браузер», «Работа по API-ключу»; переключатель языка RU и EN, шестерёнка настроек, кнопка обновления `⚡`.

**Панель чата:** выбор и переименование чата, выбор модели, «Новый чат», «В начало», «Стоп» прерывает текущий запрос и всю цепочку продолжений, блок «Дополнительно» с кнопками `Переинициализировать`, `🐞 Ошибки запуска игры`, `📡 Обновить справочник API`, `⌨ Живой ввод в браузер`, безопасное переименование, `Стоп плана`. Статус-бар показывает фазу, таймер запроса и объём ответа.

**Карточки в чате:** сообщения пользователя и агента с копированием, автосворачивание длинных ответов после 1200 символов, карточки вызовов инструментов с параметрами, чек-лист плана с отметками шагов, диффы, подтверждения, системные и ошибочные плашки, live-стрим ответа по мере генерации.

**Подсветка кода:** изменённый агентом блок подсвечивается зелёным прямо в редакторе скриптов и отмечает сам файл в списке, переподкрашиваясь при ваших правках.

**Runtime Bridge по желанию:** добавьте `agent_runtime_bridge.gd` в **Настройки проекта → Глобальные → Автозагрузки** под именем `AgentRuntimeBridge` и перезапустите редактор. Плагин регистрирует отладочный протокол сам и не трогает `project.godot` без вашего действия. После этого доступен `inspect_runtime` в debug-запуске.

**Обновления:** плагин проверяет [релизы на GitHub](https://github.com/zzzlichzzz/Godot_agent/releases/latest), показывает changelog, ставит версию и предлагает «Перезапустить редактор» или «Открыть на GitHub». Токен, язык, путь к серверу и настройки при этом сохраняются.

**Локализация:** весь интерфейс на русском и английском, переключается на стартовом экране, язык интерфейса редактора подхватывается автоматически.

## 🧪 Экспериментальное

* **mini-lich** — **заморожена, развития не планируется.** Локальная нейросеть-помощник для сцен с теневым режимом обучения осталась в коде, но её настройки скрыты в диалоге, включить из интерфейса нельзя. Плагин работает без неё.
* **MCP и внешний мост** — `python/tools/agent_bridge.py` даёт внешним ИИ (Cline, Cursor, терминал) те же данные, что и встроенный агент: кэш API движка, Библиотекарь, поиск по проекту, движок переименований, проверка кандидата настоящим Godot. Инструкция: [`python/tools/MCP_ALPHA.md`](godot_agent/python/tools/MCP_ALPHA.md).
* **Свои страницы** и универсальный парсер сайтов — в плане.

## ⚠️ Честные ограничения

* `run_check`, автоматический запуск и остановка игры, **намеренно отключён**: у Godot нет публичного API, позволяющего доказать, что debug-сессия запущена именно плагином. Игру запускайте вручную.
* `inspect_runtime` только для чтения, не более одного вызова на ход, требует debug-автозагрузки `AgentRuntimeBridge`.
* Кнопки отката теряются при повторном открытии чата, хотя нужные данные есть.
* Удаление узла не вычищает висящие ссылки в скриптах, они показываются предупреждениями.
* Переименование функции или сигнала не трогает `method=` и `signal=` в `.tscn`, для узлов используйте безопасное переименование.
* Правки `res://addons/` и файлов самого Godot Agent заблокированы по умолчанию, каталог провайдеров из models.dev и режим API ещё не проверялись живьём.
* В браузерном режиме окно Chrome и консоль сервера должны оставаться открытыми, а страницу сайта нельзя менять посреди диалога — «Новый чат» начинает чат с чистой страницы.
