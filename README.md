# 🤖 Godot AI Agent

Мощный автономный ИИ-ассистент, глубоко интегрированный в редактор **Godot 4**. 

Основная идея проекта — дать разработчику умного ИИ-напарника прямо в Godot без необходимости оплачивать дорогие токены или подписки. Плагин автоматизирует веб-интерфейсы топовых моделей (в первую очередь **Google AI Studio** с его миллионным контекстом), позволяя ИИ исследовать структуру проекта, безопасно создавать и редактировать сцены, настраивать Input Actions и Autoloads, применять точечные diff-патчи с визуальным предпросмотром и мгновенно откатывать любые ошибки.

## 🌟 Ключевые возможности

### 1. Режимы работы
* 🌐 **Основной режим — Бесплатно через Браузер (Selenium):**  
  Главная фишка и базовый сценарий использования плагина! Вы работаете с топовыми нейросетями через Chrome без покупки API-токенов. Поддерживаются **Google AI Studio** (Gemini Pro / Flash с огромным окном контекста под весь проект), **DeepSeek**, **Kimi**, **Qwen**, **Chatbot Arena**.
* 🧪 **Режим API-ключей (Экспериментально / В разработке):**  
  Дополнительный режим, находящийся на раннем этапе реализации. Добавлена базовая интеграция с совместимыми провайдерами (OpenRouter, Groq, Gemini API, OpenAI, DeepSeek, локальные Ollama), однако основной фокус и максимальная отточенность работы сейчас сосредоточены на браузерном режиме.

### 2. Глубокое понимание структуры Godot
* **Встроенный «Библиотекарь» (Librarian):**  
  Агент моментально находит релевантные скрипты, функции, сигналы, узлы и свойства через локальный семантический индекс и кэш ClassDB движка, экономя токены и время.
* **Структурная работа со сценами (`.tscn`):**  
  Создание и модификация сцен через нативное API движка (PackedScene) и специализированный парсер узлов — больше никаких сломанных UID, потерянных связей сигналов и испорченных текстовых файлов сцен.
* **Управление настройками проекта:**  
  Безопасное добавление Input Actions, Autoloads (синглтонов) и слоев коллизий в `project.godot`.
* **Правка ресурсов (`.tres`):**  
  Редактирование тем, анимаций, SpriteFrames и данных локальных ресурсов.
* **Семантический рефакторинг:**  
  Безопасное переименование функций, переменных и сигналов по всему проекту с автоматическим обновлением всех ссылок.
* **Runtime Debugger Bridge:**  
  Снятие среза состояния живой игры (дерево активной сцены, свойства узлов, ошибки) во время debug-запуска.

### 3. Безопасность и контроль над кодом
* **Интерактивный Diff Preview:**  
  Каждое изменение кода показывается в виде цветного диффа прямо в чате. Вы лично подтверждаете («Применить» / «Отклонить») любое действие.
* **Многоуровневая валидация (Headless Check):**  
  Перед применением код проверяется встроенными линтерами (`gd_lint`, `tscn_lint`), а также настоящим движком Godot в headless-режиме, отсекая синтаксические и архитектурные ошибки до того, как они попадут в проект.
* **Атомарные транзакции и мгновенный откат (Undo / Rollback):**  
  Все изменения логируются в журнал `.agent_history` — любой шаг или сложный многосоставной план можно откатить в один клик.
* **Защита аддонов и системных файлов:**  
  Агент изолирован от системных директорий и папки `res://addons/` (правки аддонов блокируются, если пользователь явно не попросил об этом).

### 4. Нативный интерфейс для Godot Editor
* Полная адаптация под тему оформления и системные иконки вашего редактора Godot.
* Компонентная система карточек: аккуратная подсветка синтаксиса, пошаговые чек-листы выполнения задач (Plan Checklist), карточки вызова инструментов (Tool Calls) и статус-бар сервера.

## 🚀 Установка и быстрый старт

### Требования
* **Godot Engine 4.x** (протестировано на версиях 4.3–4.6+)
* Для браузерного режима: установленный браузер **Google Chrome**

### Шаги установки

1. **Скопируйте плагин в проект:**  
   Поместите папку аддона в ваш проект Godot так, чтобы путь имел вид:  
   `res://addons/Godot_agent/godot_agent/`

2. **Включите плагин в настройках:**  
   В верхнем меню Godot откройте: **Проект → Настройки Проекта → Модули (Plugins)** и поставьте галочку напротив **Godot Agent**.

3. **Откройте панель агента:**  
   В правой док-панели редактора появится вкладка **Agent**.

4. **Запуск и подключение:**  
   * Нажмите **«Новый чат»** — плагин автоматически свяжется с локальным сервером и откроет окно Google Chrome.
   * **Основной сценарий:** в открывшемся окне нажмите на карточку **Google AI Studio** (или другого сайта) и авторизуйтесь. Браузер и консоль сервера закрывать не нужно — через них плагин взаимодействует с моделью.
   * *(Опционально)* Если вы хотите протестировать экспериментальный режим API — в настройках можно указать свой ключ провайдера, но для основной стабильной работы рекомендуется браузерный режим.

5. **Готово к работе:**  
   Пишите запросы на русском или английском языке — от создания простых скриптов движения до генерации игровых механик и исправления багов в сценах!
