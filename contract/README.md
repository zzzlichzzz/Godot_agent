# contract/

Единственный источник правды по протоколу (R-05, R-15).

- `editor_verbs.json` - словарь примитивов моста (R-14);
- `errors.json` - допустимые коды ошибок (R-15);
- `capabilities/*.json` - схемы возможностей.

Схемы генерируются `tools/gen_contract.py` из дескрипторов модулей.
Руками не правятся: расхождение схемы и кода - дефект.
