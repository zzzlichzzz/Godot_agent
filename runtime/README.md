# runtime - половина плагина, которая работает В ИГРЕ

`agent_runtime_bridge.gd` старого агента — не редакторный код: он живёт
в запущенной игре, собирает шаги проверки, снимок дерева, свойства,
метрики и шлёт отчёт через debugger-канал. Поэтому он вынесен из
`editor/` в отдельную папку: у него другой хост, другой жизненный цикл
и другой профиль отказа.
