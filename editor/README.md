# editor/

GDScript-сторона плагина. Правило R-14: здесь только примитивы редактора,
транспорт, настройки и UI. Никакого разбора `.gd`/`.tscn`, линта, diff, планов
и политики путей - это Python-часть.

| папка | роль |
|---|---|
| `core/` | жизненный цикл, состояние, настройки, i18n, обновление |
| `bridge/server/` | сокет, сессия, кадрирование |
| `bridge/dispatch/` | приём примитива, главный поток, таблица обработчиков |
| `bridge/verbs/` | примитивы по областям: scene, project, editors, ui, runtime |
| `ui/` | панель, чат, карточки, стартовый экран, статус, тема |
| `settings/` | хранение и экран настроек |

Словарь примитивов фиксируется в `contract/editor_verbs.json` (R-14).
